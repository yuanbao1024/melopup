# 📖 项目简介

MeloPup 是基于现代前端技术 + 主流大模型 API 打造的桌面级 AI 音乐陪伴应用，摒弃传统播放器单一听歌模式，以拟人化交互形态为核心，实现听歌娱乐 + 智能聊天 + 情绪治愈 + 音乐智能推荐一体化体验。
用户可随心播放全网音乐，同时与专属 AI 智能体实时对话倾诉心事、闲聊互动，依托大模型语义理解能力感知用户情绪，匹配对应曲风音乐与暖心回应，让音乐不止是旋律，更是专属情感陪伴伙伴。
项目全程采用 Vibe Coding 模式独立开发，从界面设计、交互逻辑、接口联调至功能闭环全部自研完成，现已正式稳定上线，持续迭代优化交互体验与情感感知能力，致力打造拥有独立灵魂的沉浸式 AI 音乐陪伴生态。

# 🛠️ 技术架构

前端技术栈
核心框架：Vue3 + Vite 极速构建开发
语法规范：TypeScript 强类型约束，代码健壮易维护
样式方案：UnoCSS / SCSS 轻量化样式开发
状态管理：Pinia 全局状态统一管理
网络请求：Axios 封装统一请求拦截
界面动效：原生 CSS 动画 + 轻量化交互动效
3D 视觉：Spline 轻量化 3D 场景嵌入，提升整体氛围感
后端 & 接口服务
AI 能力对接：DeepSeek 大模型 API 作为核心对话大脑
音乐数据源：对接主流音乐平台接口，实现歌单、播放、搜索全能力
环境配置：Vite 全局环境变量统一管理密钥与接口地址
部署方案：Vercel 一键云端自动部署，支持自定义域名绑定
数据处理：前端轻量数据解析、格式统一适配
整体架构流程
用户端发起音乐播放 / AI 对话请求
前端完成请求封装、参数校验与页面交互渲染
转发请求至对应音乐接口 & 大模型对话接口
接收云端返回数据，完成解析、排版、情绪逻辑处理
前端实时渲染音乐播放器界面 + AI 拟人化回复内容
全局状态留存对话上下文，实现连续连贯对话交互

# 🚀 快速部署运行

环境依赖
Node.js >= 18.x
Git
本地运行
bash
运行
克隆项目
git clone https://github.com/你的用户名/MeloPup.git

进入项目目录
cd MeloPup

安装依赖
npm install

本地启动开发环境
npm run dev

项目打包构建
npm run build
环境变量配置
在项目根目录新建 .env 文件，填写对应密钥配置
env
大模型接口地址
VITE_OPENAI_BASE_URL=你的模型接口地址
大模型API密钥
VITE_OPENAI_API_KEY=你的API密钥
调用模型名称
VITE_OPENAI_MODEL=选用模型名
音乐平台授权Cookie
VITE_NETEASE_COOKIE=音乐平台登录凭证
云端部署
支持直接导入 Vercel / Netlify 一键自动部署，填入对应环境变量即可完成上线，支持绑定个人自定义域名。
